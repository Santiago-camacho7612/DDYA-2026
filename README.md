# DDYA-2026

Repositorio creado para almacenar y organizar los trabajos, ejercicios y laboratorios realizados durante la materia **DDYA** en el año 2026.

## Descripción

En este repositorio se encuentran las diferentes actividades desarrolladas durante el semestre.  
Los archivos están organizados por semanas para facilitar su consulta y mantener un registro ordenado del trabajo realizado en clase.

## Estructura del repositorio

Actualmente el repositorio está organizado de la siguiente manera:

- **Semana 1:** Actividades correspondientes a la primera semana.
- **Semana 3:** Actividades correspondientes a la tercera semana.
- **Semana 4:** Actividades correspondientes a la cuarta semana.
- **Semana 5:** Actividades correspondientes a la quinta semana.
- **dev-pr-dynamic:** Archivos relacionados con las prácticas desarrolladas durante el curso.

A medida que avance el semestre se agregarán nuevas actividades y carpetas.

## Objetivo

El objetivo de este repositorio es llevar un registro de los trabajos realizados durante la materia DDYA, permitiendo almacenar, organizar y compartir los diferentes ejercicios y proyectos desarrollados.
